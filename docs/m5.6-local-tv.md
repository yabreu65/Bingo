# M5.6 — Multimedia local en la TV

> **M6 T6:** LOCAL_TV permanece bloqueado en builds de producción hasta su certificación. No hay fallback automático a SERVER; la TV muestra un aviso y no solicita medios. El procedimiento siguiente conserva valor para desarrollo y futura certificación. Ver `m6-t6-boundaries.md`.

## Arquitectura

El servidor central conserva la autoridad del juego, las sesiones TV, los `challengeId`, los temporizadores, la puntuación y la finalización de retos. La sala `REMOTE_PRESENTIAL` puede seleccionar `multimediaPolicy.tvMediaSource=LOCAL_TV`.

La laptop conectada a la TV ejecuta `tools/local-tv-media-server.mjs`, que escucha únicamente en `127.0.0.1`. El servidor recibe un manifiesto generado localmente, pero nunca recibe las rutas absolutas ni los archivos. La aplicación TV convierte cada ruta relativa en un identificador determinista `m_<hex>` y solicita `/media/<id>` al servicio loopback.

No se usa `file://`, no se permite listado de directorios y el servidor local solo sirve extensiones incluidas en el manifiesto. Cada respuesta admite `GET`, `HEAD` y rangos HTTP para reproducción HTML5.

## Instalación en la sede

1. Usar una copia autorizada de la biblioteca multimedia en la laptop conectada a la TV. No copiarla al repositorio ni al servidor central.
2. Desde el repositorio, generar el manifiesto:

   ```bash
   node tools/generate-local-tv-manifest.mjs \
     --root /ruta/a/la/biblioteca-autorizada \
     --out /ruta/privada/tv-media-manifest.json
   ```

3. Iniciar el servicio solo en loopback:

   ```bash
   node tools/local-tv-media-server.mjs \
     --root /ruta/a/la/biblioteca-autorizada \
     --manifest /ruta/privada/tv-media-manifest.json \
     --port 8787 \
     --allow-origin https://evento.example
   ```

4. Comprobar `http://127.0.0.1:8787/health` en la misma laptop.
5. Crear la sala como `REMOTE_PRESENTIAL`, seleccionar `LOCAL_TV` en la fuente multimedia y abrir el enlace temporal de TV en el navegador conectado al televisor.
6. Aprobar el permiso de red local/loopback si el navegador lo solicita.
7. Verificar en la pantalla de TV que el estado indique servicio local disponible o reproducción local activa. También se puede confirmar en las herramientas del navegador que el recurso usa `http://127.0.0.1:8787/media/m_...` y que no se solicitó `/music/` al servidor central.

## Límites de navegador

La página pública debe servirse por HTTPS. `127.0.0.1` puede considerarse un origen potencialmente confiable, pero las políticas de contenido mixto y Local Network Access varían por navegador y versión. No se deben desactivar protecciones globales. Si el navegador bloquea el recurso loopback, utilizar `SERVER` para esa sesión; no convertir el bloqueo en una excepción de seguridad.

El servicio local no se expone a la red Wi-Fi y no reemplaza la conexión Socket.IO/WSS con el servidor central. La modalidad local solo cambia la fuente de los bytes multimedia de la TV.

## Parada y contingencia

- Detener el proceso con `Ctrl+C` al terminar la partida.
- Si el manifiesto no contiene un recurso, la TV informa el error y el juego continúa bajo control del servidor.
- Si la laptop pierde la biblioteca o el navegador bloquea el acceso, revocar/reabrir la TV con `SERVER` y utilizar únicamente recursos sintéticos o autorizados.
- No abrir el puerto 8787 en el firewall, no crear túneles y no servir la biblioteca desde `0.0.0.0`.
