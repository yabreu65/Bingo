# Repository Instructions

## Scope

These instructions apply to the Bingo Bailable repository.

## Git

- Use Conventional Commits.
- Do not add `Co-Authored-By` or AI attribution to commits.
- Keep commits focused on one reviewable work unit.

## Validation

- Run the relevant backend tests and frontend lint/build before delivery.
- Do not commit secrets, environment files, dependency directories, build output, runtime logs, uploads, or local multimedia assets.

## Code Quality

- Preserve the existing backend/frontend separation.
- Keep tests with the behavior they verify.
- Prefer explicit error handling and validated inputs.
